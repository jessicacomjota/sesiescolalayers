\# SGA Layers



\## Sistema de Gestão de Atendimentos Layers



Sistema desenvolvido para gerenciamento, acompanhamento e análise dos chamados registrados no aplicativo Layers.



\### Funcionalidades



\* Dashboard de atendimentos

\* Consulta de chamados

\* Filtros por status, assunto e canal

\* Busca de chamados

\* Detalhamento individual

\* Análise dos atendimentos

\* Acompanhamento de pendências

\* Relatório geral

\* Exportação de dados

\* Geração de relatórios em Excel, Word e PDF

\* Gráficos e indicadores de atendimento



\### Tecnologias utilizadas



\* Python

\* Streamlit

\* Pandas

\* Plotly

\* OpenPyXL

\* Python-docx

\* ReportLab

\* Kaleido



\### Segurança



Os arquivos contendo dados dos chamados e informações de acesso não fazem parte do repositório público.



As credenciais do sistema são configuradas por meio dos \*\*Secrets do Streamlit\*\*.



\### Execução local



Para executar o sistema localmente:



```bash

python -m streamlit run app.py

```
